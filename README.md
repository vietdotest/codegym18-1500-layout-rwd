# Layout với RWD

Bài CodeGym 1500. Trang đề thiếu ảnh mẫu; bố cục được tự chọn theo yêu cầu của người học.

## Chạy
Mở index.html trên trình duyệt.

## Bố cục
Header/menu, sidebar chủ đề, main có ba card và cột ghi chú, footer. Desktop ba cột, tablet hai cột, mobile một cột. Dùng DIV và CSS Grid/Flexbox cùng media query, có meta viewport.
